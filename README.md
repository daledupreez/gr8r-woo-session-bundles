# Gr8r Session Bundles for WooCommerce

A WordPress plugin that makes it possible to create bundles of other products in WooCommerce. The goal is to create bundles of multiple products with custom quantities, with the primary goal of supporting bundles of bookable sessions with Dokan, WooCommerce Bookings, and WooCommerce Subscriptions.

## Features

- **New Product Fiels**: Adds Session Bundle options for simple products in WooCommerce
- **Product Selection**: Choose from existing WooCommerce products to include in bundles
- **Quantity Management**: Specify custom quantities for each bundled product
- **Frontend Display**: Beautiful display of bundle contents on product pages
- **Cart Integration**: Bundle information displayed in cart and checkout
- **Responsive Design**: Mobile-friendly interface for both admin and frontend

## Installation

1. **Upload the Plugin**:
   - Upload the `gr8r-woo-session-bundles` folder to your `/wp-content/plugins/` directory
   - Or zip the folder and upload via WordPress admin

2. **Activate the Plugin**:
   - Go to **Plugins > Installed Plugins** in your WordPress admin
   - Find "Gr8r WooCommerce Session Bundles" and click **Activate**
